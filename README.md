# Rock Paper Scissors

Think you have what it takes to beat the computer?  Test your strategy & luck with this interactive Rock Paper Scissors game, built with HTML, CSS, JavaScript.
Track your wins, losses, ties, & reset to challenge yourself again.

## Features

- Play againt the computer with randomized Rock, Paper, or Scissors choices.
- Live scoreboard that tracks wins, losses, ties, & total rounds played.
- Automatic win percentage calculation that updates after every round.
- Reset button clears scores and starts fresh.
